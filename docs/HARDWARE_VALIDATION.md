## Picoの機器別確認

| 対象 | 動作確認 | 精度・追加条件 |
|---|---|---|
| 電源基板・INA226 | ID、電圧/電流取得、ALERT入力 | テスターと複数負荷で比較、シャント・測定器の誤差を記録 |
| microSD・検出端子 | 512B読戻し、連続記録、停止後CSV検証、停止・電源断後の有無比較 | CRC/連番/時間とSDエラー。既存ファイルを保持 |
| 状態LED | 点滅・同期時の点灯を目視 | USBだけでは点灯確認を代替できない |
| ボタン | 未押下・上・決定・下のADC値 | 約3.3/0/0.82/1.65Vと比較。現ファームは起動時確認のみのため診断追加が必要 |
| RTC（接続時） | 型番確認、時刻進行、発振停止フラグ、保持 | GNSS基準と比較。バックアップ評価は主電源断が必要。診断追加が必要 |
| 磁気センサ（接続時） | 型番/ID、3軸出力と回転応答 | 校正・姿勢・周囲磁場を記録。絶対方位は独立基準が必要。診断追加が必要 |
| TX基板（接続時） | 今回の取得実験ではGP16 Low、対象と給電状態の確認 | 音響送信試験は現取得ファームの範囲外。試験条件を別途確定する |
| TX温度（接続時） | 回路・センサ型番を確認後、ADC取得 | 換算式と比較温度計が必要。診断追加が必要 |

RX、水温、水圧、テザー、LCDはユーザー申告で未接続。外付けGNSSはSpresense PPSと競合するため未接続を確認する。

## 精度評価の解釈

- IMUの出力単位・軸方向は使用ドライバーの一次資料と実物型番で確認してから換算する。静止標準偏差はノイズ、平均はオフセット評価に使う。回転台がなければ既知角速度に対するジャイロ感度の精度は評価できない。
- GPSは緯度経度を局所座標のメートルへ換算する。測定平均からの95%半径は再現性であり絶対位置精度ではない。測量済み基準を使う場合は基準の不確かさ、座標系、アンテナ位置、高さ基準を記録する。
- `sync=1`はファームのPPS対応条件成立。周期が約1秒でもUTCの1秒ずれや一定の割り込み遅延は排除できない。PCのUSB受信時刻はUSB/OS遅延を含むのでマイクロ秒精度の基準にしない。
- 時刻誤差は同じイベントについて機体の付けたUTCと独立基準UTCとの差を測る。外部測定用信号が必要なら未使用ピンと実配線を確認し、計測用ファーム変更も記録する。
- 精度の要求値が未指定の場合、測れた範囲の誤差分布と測定限界を報告する。任意のしきい値を満たしただけで用途に対する精度合格とはしない。
