実験操作

測距・マルチパス記録の設定

回数は送信枠の設定です。観測中・操作通信中・応答遅延時は休止します。連続測距には観測記録を無効にしてください。3連は各5波の間隔を毎回変更します。64種類から選び、テザーで通知したパターンだけを採用します。同じパターンの再使用は4回/秒で最短16秒後です。反射の低減効果・距離精度は未検証です。

観測状態を確認中…

受信後の包絡線を20 kサンプル/秒と比較器のエッジ時刻で子機SDへ保存します。200 kHz等の搬送波そのものの波形ではありません。最初の送信を記録対象にし、その後は指定回数ごとに記録します。観測中は次の音響送信を休止し、終了後に設定した周期へ戻ります。記録時間・頻度を上げると保存負荷が増えます。設定は再起動で1回/秒・可変3連・200 kHz・3秒・30回に1回に戻ります。周波数ごとの振動子・回路の応答と距離精度は未検証です。

親機 LIS3MDL 磁気キャリブレーション

親機の3軸オフセットと倍率を補正します。開始すると測距と親機のSD記録（PPKを含む）を停止します。子機の記録は継続します。校正保存には親機SDが必要です。

未取得

  1. 組み上げた親機を磁石・スピーカー・大きな金属から離します。
  2. 上下・左右・前後の向きを変えながら、全方向へゆっくり回します。水平面の8の字だけで終えないでください。
  3. 20秒以上・200サンプル以上、3軸の十分な変化と全8方向のデータが揃うと保存可能になります。
  4. 保存後に「校正を終了」を押し、実験タブから記録を再開してください。3分で自動終了します。

飽和が一度でもあると保存できません。磁気源から離して終了・再開始してください。再起動時は同じSDから保存済み補正を読み込みます。校正は軸別の簡易補正で、方位角の精度合格や軸間の歪み補正を保証しません。GNSSにはこの回転校正は不要です。アンテナ情報は時刻・位置タブで設定します。

BNO085 キャリブレーション

対象は子機のBNO085です。開始すると測距送信と子機SD記録を停止します。親機の記録は継続します。終了後、実験タブから記録を再開してください。

未取得。「校正状態を更新」で確認できます。

  1. 組み上げた子機を、磁石・スピーカー・大きな金属から離して置きます。
  2. 4〜6方向に姿勢を変え、各姿勢で約1秒静止します。
  3. 台の上で2〜3秒静止します。
  4. 各軸で約180度回し、元へ戻します。1軸あたり約2秒を目安に繰り返します。
  5. 加速度・ジャイロ・磁気がすべて「中」以上で5秒続くと保存可能です。「保存」を押し、応答を確認してから「終了」を押します。

校正中の磁気レポートは50Hz。状態0〜3はセンサー自身の判定で、角度精度の測定結果ではありません。姿勢は従来のGame Rotation Vectorのままで、磁北基準には変えません。保存はBNO内部のDCDへ行い、SDログは変更しません。終了操作は開始前の動的校正設定と磁気20Hzへ戻します。10分で自動終了しますが、復帰に失敗した場合は「校正を終了」で再試行してください。未保存の終了でもRAM上の補正は巻き戻らず、BNOの既存の自動保存設定も変えません。
