# 現在受信中のGPS・PPSとSD停止状態の確認

| 項目 | 内容 |
|---|---|
| 実施日 | 2026-09-21 JST |
| 対象 | Spresense b7cd3c6、COM7でUSB識別後に確認 |
| 目的 | 親機の「異常・停止」表示の原因と現在のGPS/PPSを確認 |
| 判定 | GPS測位・PPS対応条件成立。SDは前回の安全停止状態、エラー0 |

## 前提・接続機器

窓を開放した継続セッション。Sonyメイン・拡張ボード、SPI5 Multi-IMU（960 Hz設定）、SDHCIのSD、USB接続。SD容量・型番と電源電圧は未測定。親機・子機のUSBは検出されず、親機画面の表示はユーザー申告。RX・水温・水圧・LCDは対象外。

| 信号 | 接続 |
|---|---|
| PPS自己入力 | 拡張D02→D03、JP1=3.3V（前回ユーザー確認） |
| 親機PPS | 拡張D02→既存100Ω→親機GP6（物理9） |
| 親機UART | 拡張D01→既存100Ω→親機GP7（物理10）、共通GND |
| IMU / SD | Sony SPI5 / 拡張SDHCI |

## 手順・結果

シリアルをリセットせずに約6秒間読み取り。書込み・再起動・保存停止命令は今回送っていない。[状態ログ](evidence/status.txt)は位置情報を含まない。

| 項目 | 実測 |
|---|---|
| GPS | fix=3（3D）、使用6衛星、可視6衛星、flags=11 |
| PPS | count=530→535、毎秒増加 |
| UTC | utc_source=2、utc_sync_valid=1、通知経過約0.592秒 |
| IMU | samples=449,235→454,058、取得継続、エラー・欠落0 |
| SD | sd=0、sd_rows=264,311で固定、sd_errors=0 |
| Formatter | エラー0、処理数12,836で固定 |

保存行数は実験022の安全停止時と同じ。実験022ではSTOPPED_REMOVE_SDを確認済み。現在のSD状態はその正常停止が継続しているもので、今回観測した範囲に新たなSD故障を示すエラーはない。UART flags=11はGPS時刻・位置・IMU有効、SD保存中ビットなしを表す。親機Webは保存中ビットなしを異常／未準備として表示するため、正常停止も異常に見える。

## 限界と現在の状態

UTC同期フラグはPPSとGNSS秒の対応条件成立を表す。絶対UTC精度やIMU測定瞬間の精度を実測合格にしたものではない。今回GPS取得後の新しいSDデータは保存されておらず、その保存・回収検証は未実施。

**SD記録は停止したまま。** 現行Sonyファームの操作は停止q・回収i/gで、同一起動中の記録再開操作は未実装。再起動すると新しいファイルに自動記録を開始するが、GPSも再起動して再受信が必要となるため、今回の状態確認では再起動していない。親機側の表示変更も行っていない。
