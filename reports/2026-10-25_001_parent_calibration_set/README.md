# 親機校正セットの公開操作画面

## 前提
2026-10-25 JST。ユーザーの「最後まで進めてください」に基づき、親機実装済みのPPS状態・サンプル記録・親機校正セットを公開専用checkoutの操作画面へ反映する。元のAquaBeacon/P_MAIN_experiment作業フォルダーは変更しない。生ログ・認証情報・実測位置は公開しない。PC Wi-Fi切替・実機Web操作はしない。

## 実施
既存センサー校正タブにセット名/CAD版/機体・センサ識別/配置・方向/個別校正参照を追加。D02 PPS検出・UTC対応・IMU推定時刻を分離表示。下書き/不一致/通信失効を表示する。親機接続・role確認後だけ操作と時刻共有を許可する既存の公開版ラッパーを維持し、新規APIも親機へ転送する。キャッシュ版を20261025-v9へ更新する。

## 検証
公開版の模擬接続・role確認・新規API転送・オンライン/オフラインキャッシュ試験を実施する。公開後に配信HTMLとコミット内容の一致を確認する。結果とcommit/CI URLは完了時に追記する。

## 未検証
スマホの実接続/権限/キャッシュ更新、実機Web操作、PPS絶対精度、実機センサ校正・CAD配置・姿勢/位置精度は未検証。サンプル回路をPPSで駆動する方式ではなく、内部時計からの推定時刻である。
