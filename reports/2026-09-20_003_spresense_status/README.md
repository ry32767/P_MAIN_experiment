# Spresense・GPS時刻同期のWeb表示

- 日時：2026-09-20 JST
- 目的：通電中のSpresenseからGPSと時刻同期の状態を取得し、統合Web画面に表示する。
- 対象：AquaBeacon MAIN親機と公開Pages。公開変更元a3f7e2d、画面は本レポートと同じコミットに収録。
- 前提：J_SPR1.1=Spresense D02→GP6、J_SPR1.2=D01→GP7、GND共通。AquaBeacon/pcb/BRINGUP_BOARDS.mdの実配線記載と既存P_MAIN_experimentの実装を照合。信号は入力専用。既存Spresense AQB1送信を利用し、Spresenseへの書込みなし。
- 対象外：LCD、親機温度・水圧・磁気センサー、距離精度評価。PC Wi-Fiは切り替えない。
- 環境：Windows、既存PlatformIO/Arduino-Pico、Python、Node.js、Zig C++。

## 実装と検証

受信・PPS取得は親機core1で処理し、SD/Wi-Fiの待ち時間から分離。受信ループには処理量上限を設定。テザーのパケット形式は変更せず、子機の書込みは不要。親機USB番号とP_MAIN応答の両方を照合し、保存停止を確認して書込み。

屋外等で測位成立後のUTC対応、絶対時刻精度と1秒対応ずれ、実機ブラウザー表示は未検証。公開ページの実機操作はユーザーが確認する。

## Spresense・GPS時刻同期の状態表示

2026-09-20の通電開始に伴い、親機GP6でSpresense D02の1PPS、GP7でD01のAQB1 UART（115200 bps・受信専用PIO）を受信します。外付けGNSS用GP8/GP9は使用しません。既存Spresenseファームウェアは変更不要です。

WebはSpresense通信、GPS測位成立、測位使用衛星数、1PPS検出と周期、GPS時刻の有効性、親機とUTCの対応、Spresense SD/IMU状態を別々に表示します。現在のAQB1データには可視衛星数・信号強度がないため、未測位時の電波受信有無は「不明」とします。通信途絶時は過去の測位状態を現在値として表示しません。

UTC対応は、1PPSと有効UTCの連続3組、約1秒の周期、UART受信が直前PPSの20〜800 ms後という既存実験の条件を利用します。時刻ラベルが直前PPSに対応すること・絶対時刻精度は未検証です。APIの`spresense.sync_candidate`で条件成立を示し、`utc_candidate_us`は参考値です。従来の`utc_valid=false`は精度未検証として維持します。GPS通信は3秒、同期は1.5秒の期限で失効し、画面も更新停止3秒で不明表示になります。

子機のテザー同期と測距は親機の単調時刻を引き続き使用します。今回UTCを子機へ配信したり、既存SDログの時刻をUTCに変更したりはしません。`P_MAIN_GNSS_RESERVED`は引き続き予約ファイルです。
