# 親機LIS3MDLの磁気キャリブレーション

親機コンソールの「センサ校正」タブから開始・保存・終了・補正解除を行う。BNO085の内部校正とは別に、LIS3MDLの生磁気データを親機で補正する。Spresenseは変更しない。GNSSにこの回転校正は行わず、アンテナ型番・高さは「時刻・位置」で設定する。

## 操作

1. 組み上げた親機を磁石・スピーカー・大きな金属から離す。同じSDカードを用意する。
2. 「親機の記録を停止して校正開始」を押す。測距送信と親機SD記録（PPKを含む）が停止する。子機記録は継続する。
3. 上下・左右・前後を含む全方向へゆっくり回す。水平の8の字だけでは不足する。生値・補正値、変化幅、方向数、サンプル数、ばらつきを確認する。
4. 保存可能になったら「校正結果をSDへ保存・適用」を押す。「保存・適用済み」を確認して「校正を終了」を押す。
5. 実験タブから記録を再開する。自動再開しない。

3分で自動終了する。未保存で終了した場合、以前の保存済み補正を維持する。飽和が一度でもあれば保存できないので、磁気源から離して終了・再開始する。「保存した補正を解除」は終了後、親機の記録停止中に押す。無補正の新規レコードを保存し、以前のファイルは削除しない。

## 計算・保存条件

LIS3MDLは±4 gauss、10Hz、BDUで取得。生値は68.42 LSB/µTで換算。軸ごとの最小・最大からオフセット=(最大+最小)/2、半径=(最大−最小)/2、倍率=3軸の平均半径/各半径を計算し、補正値=(生値−オフセット)×倍率とする。表示・健康状態・MAGログへ適用する。

保存には20秒以上・200サンプル以上、各軸の変化幅30〜200µT、補正中心を基準とする8方向に各5点以上、補正半径の変動係数15%以下、平均半径が目標の85〜115%、正常で新鮮なデータが必要。最大1800点。飽和・非数・範囲外補正を拒否し、通信失敗や300ms以上更新がない値は正常な磁気値として扱わない。これらは回転範囲と整合性の判定であり、方位精度の測定結果ではない。

補正は軸別の簡易モデル。軸間の歪みを含む完全な楕円体補正、機体の取り付け方向、傾斜補正、磁気偏角、磁北方位の精度保証は含まない。

親機停止完了後にSDへ新規 `P_MAIN_MAGCAL_00001.bin` 等を排他的作成し、同期と読み戻しが成功してから適用する。CRC32・版・長さ・補正値を検査し、起動時は同じSDの有効な最大連番を読み込む。壊れたレコードは使わない。既存ログの削除・上書き・SDフォーマットは行わない。保存要求の再送は同じセッションで重複作成しない。

APIは操作ヘッダー付きPOST `/api/mag/start`、`save`、`end`、`reset`。状態は `/api/status` の `mag_calibration`。校正中の親機記録開始・測距開始は拒否する。

根拠: [ST AN3192](https://www.st.com/resource/en/application_note/an3192-3axis-magnetometer-calibration-and-compensation-stmicroelectronics.pdf)。本実装の保存条件はプロジェクト独自の判定基準。
