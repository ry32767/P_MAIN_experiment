# BNO085 3軸手動回転試験

| 項目 | 内容 |
|---|---|
| 実施日時 | 2026-09-22 JST |
| 目的 | C_MAINのBNO085を平置き、X/Y/Z軸まわりに手動回転し、姿勢・加速度・角速度とSD保存の実応答を確認する |
| 対象 | C_MAIN / Pico 2 W / BNO085、100 Hz構成、`C_MAIN_IMU_100Hz_00009.csv` |
| 判定 | 合格。3軸とも指定軸に対応する応答、全行CRC一致、全イベント連番欠落0。手動角度のため絶対角度校正は未実施 |

## 前提条件

子機COM3（USB serial `A521D21EB1DCFB44`）のみ操作。親機COM6は接続中だが、シリアル操作・停止・書込み・ファイル回収を行っていない。ユーザーがBNO085基板を操作し、平置き静止、BNOシルクX軸まわり約90°、平置きへ復帰後Y軸まわり約90°、平置きへ復帰後Z軸まわり時計方向約90°の順に保持した。

操作角度は治具や角度計で拘束していない。時刻窓はUSB状態のC_MAIN単調時刻を使い、各保持区間の末尾5秒を平均した。BNOの取り付け方向・シルク方向はユーザー操作に基づき、外部モーションキャプチャとの比較はしていない。

## 何をしたか

1. 子機だけを安全停止し、新規ログを開始した。
2. 平置き静止を約10秒記録した。
3. X、Y、Zの順で手動回転し、各姿勢を約15秒記録した。ログは区間間も連続保存した。
4. 子機だけを安全停止し、IMU・全BNOイベント・ヘルスの3ファイルをUSBで全量読戻しした。
5. 全行CRC、ゼロ埋め、BNO sensor_id別8bit連番、値の多様性を検査した。
6. 各保持区間の平均加速度と四元数を計算し、平置き基準からの相対回転軸・角度を求めた。

## 未検証事項・次の確認

- 90°治具・角度計を使っていないため、103～114°という値からBNO085の絶対角度誤差を評価しない。
- 平置き基準からX/Yへ回す途中で基板方位も動いており、相対四元数軸には副成分がある。重力軸の移動と最大軸成分により配線・デコードの対応を確認した。
- 磁気は周辺磁性体の影響を受けるため、方位精度や磁気校正は未合格。
- BNO内部`source_us`の微小逆転という既知課題は、本試験のCRC・連番・軸応答の合格とは別に扱う。
