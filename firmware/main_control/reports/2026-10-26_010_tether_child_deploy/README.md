## 変更
1. Spresenseの通常操作欄から補正解除を移し、右下を強調した「保存済み補正を使って次へ」に変更。センサ値やSDを変更せず磁気校正項目へ進む。
2. SAVED状態でも記録停止中なら「校正モードを終了（補正を維持）」を選べる。保存直後に無効化だけが押せる状況を解消。
3. 無効化は閉じた詳細操作へ分離。確認チェックを入れた時だけ選択でき、クリック時にも検査。状態失効/記録中/校正中/処理中等はチェック解除。APIもconfirm_disable=1がなければ409で拒否。
4. 復元値を使う姿勢欄は「保存済み補正を使用」とし、今回の未測定を未校正と混同しない表示に変更。
5. 子機のカメラ動作未完了ガードがSCHEDULE全体を除外し、相対同期まで妨げていた問題を修正。一致するsession/seqでは時計を更新し、校正/カメラ条件は音響待受けだけに適用する。測距前の必須動作は維持。
