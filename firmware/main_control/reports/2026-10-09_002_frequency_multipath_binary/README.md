# 周波数選択・間引きマルチパス観測・バイナリ保存

## 前提

- 依頼: 親機Webで10/50/100/200 kHzを変更、受信後数秒の受信情報を負荷調整してSD保存、全新規CSVログをbinaryへ変更。
- ユーザーが初期観測設定「3秒・30回に1回」を選択。観測中の後続音響送信休止もこの設定案で了承済み。
- 今回は測距頻度増加・符号化を実装しない。通常の1秒周期・5波、テザー受信エッジによる片道ToF・近接参考距離を維持。
- ピン変更なし。GP0/GP1 RS485、親機GP16送信、子機GP2比較器・GP26包絡線をinclude/pins.hに基づいて使用。隣接AquaBeaconの基板設計は既存照合を踏襲し変更なし。実配線の今回再確認は未実施。
- 実機書込み・通電操作・PC Wi-Fi変更は実施しない。Spresense GP6/GP7、親機未接続温度・水圧・LCDの扱いは変更なし。

## 実施

- Webの周波数4択、観測時間1〜5秒、観測頻度無効/毎回/5/10/30/60/300枠に1回を追加。設定操作は送信停止→設定受理、送信再開は明示操作。APIの異常値・送信中設定を拒否。
- 親機は設定をSCHEDULEへ含め、PIO分周で周波数を変更。観測対象は最初の枠と指定回数ごとの枠、設定変更で対象カウンタをリセット。
- 観測対象では子機core0が送信前にADC DMAを準備、core1が最初の音響受信時刻を通知。受信後のENV包絡線20 kSa/sと比較器エッジ時刻を観測ファイルへ保存。
- 対象送信後、観測秒数＋0.5秒は親機の後続音響送信を休止。テザー通信・BNO/I2C取得は継続。ADCを使うボタン/通常ENV値は観測中直前値となる。
- 子機SDが正常でない枠は対象選択しない。SDを止める既存のゲイン確認には観測休止を挿入しない。このゲートもホスト検証。
- 包絡線を最大1024サンプルのブロック単位で保存。SD処理の長時間停止などによるDMA上書きを検出し、実サンプル番号の飛びと欠損数を記録。比較器/要求キュー欠落も記録・表示。
- 全新規SDデータをAQBIN001 binaryへ変更。ヘッダ32 byte・レコードヘッダ24 byte・CRC32。固定IMUはpayload93 byte、BNOイベント46 byte、ヘルス205 byte。既存CSV/Vxxxxx.BINは保持し、フォーマット・削除・上書きなし。
- テザー通信version=3、156 byte。親子両方の更新が必要。
- Web一覧・回収はbinと旧csv対応。USB回収はファイル長で読む方式に変更。PCデコーダ、種類別CSV展開、既存IMU/BNO検証ツールの新bin対応を追加。
- README.md、docs/spec.md、docs/binary_log.md、docs/README.mdを更新。

## 検証結果・実測

- 指定PlatformIO環境でparent / child100 / child50のビルド成功。
- 既存開発環境Pythonでscripts/test_host.py成功。通常Pythonにはziglangがないため既存venvを使用。
- 設定境界、4周波数、間引き、観測休止時間、64 bit受信基準とADC index、DMA上書き欠損・端数ブロックをホスト検証。
- C++生成ログとPythonデコーダで全9レコード種別のフィールド・符号・浮動小数・CRCを相互確認。破損、末尾切断、CSV展開、欠損/ADCエラー/不正な完了申告を確認。完全な小観測と重複サンプルの扱いも検証。
- scripts/test_ranging_ui.py成功。4択、設定前停止、異常設定拒否、観測欠損/通信断表示、近接距離、JavaScript構文をオフライン確認。

## 未検証・実機確認手順

1. USBシリアル番号と役割応答で両機を確認し、保存停止・syncを確認して親子の両方を書き込む。
2. ユーザーが親機Webで各周波数を適用・送信開始し、測定器で親機GP16の周波数／5波停止を確認する。振動子／回路の周波数応答は未検証。
3. 3秒・30枠に1回で子機観測取得→待機、後続音響送信休止、欠損数、BNO更新・SDエラーを確認。必要に応じ観測頻度を下げる。
4. 保存停止後、binを回収してdecode_binary.pyでCRC・サンプル番号・完了・欠損・終了理由を確認。既知配置で反射遅延を評価する。
5. SD遅延／カード不在・受信なし・手動停止時に不完全な観測を正常扱いしないことを確認する。カード抜去・電源断は今回未試験。

ENVは包絡線で、搬送波そのものの高周波波形ではない。割込み/ADC起動時刻と電気・音響遅延は未校正。取りこぼしのないマルチパス観測や距離精度を保証しない。
