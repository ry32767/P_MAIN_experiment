# 学園都市・長田高校周辺の無料RTK基準局候補

## 前提
- 調査日：2026-10-25。神戸市の学園都市駅周辺と兵庫県立長田高校周辺を対象。
- 親機はNEO-F9P（L1/L5、Galileo E1/E5a）。近さだけで候補を決めず、実際に配信される共通信号を確認。
- 距離はエリアの概略代表点（学園都市：34.68, 135.06、長田高校周辺：34.67, 135.14）からの直線距離。校舎・駅入口の精密座標ではない。
- 配信側のRTCM 1005に含まれるアンテナ基準点ECEF座標をWGS84楕円体で緯度経度へ変換して計算。局座標の正しさ・基準系・精度は未評価。
- PCのWi-Fiを変更せず、通常のインターネット接続から公開配信を取得。実機への書込み・電源操作・実機Web操作はなし。

## 実施
- geortk.jp、rtk2go.com、ntrip1.bizstation.jp、160.16.134.72:2101の公開一覧を照会。最後の接続先は接続拒否。取得できた一覧から近隣局を抽出。
- 8局へNTRIP v1・認証ヘッダーなしでそれぞれ短時間接続。GGAや個人の位置情報・認証情報は送信していない。
- RTCMのCRC24Qを検証し、1005の位置、MSM4/5/7の信号マスク、有効搬送波値と正のCNRの観測セルを解析。
- 計算と検査はPythonで実行し、CRC標準検査値と位置・距離範囲をassertで確認。信号IDはRTKLIBの一次ソースに照合。

## 事前準備と現地操作
1. 学園都市では3C722D56、長田高校ではbtf_nishiyamacho3を最初に試す。両者を互いの予備として控える。
2. 両サーバーともポート2101、今回確認した局はユーザー名・パスワード空欄。
3. サーバーを変更する際は旧サービスの認証を引き継がず、必要に応じて認証保持のチェックを外す。
4. 現地ではテザリングを有効にして局を選び、補正件数とRTK解を別々に確認する。保存操作を行う場合は記録・測距・転送を停止する。
5. 現行の設定保存は1組の接続情報。今回調べた4局を画面の複数プリセットとして追加したわけではない。ファームウェアと仕様には変更していない。

## 未検証
