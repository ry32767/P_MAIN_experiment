# 実験ごとのファイル切替
親子のUSB識別、停止同期、新規ファイル作成、ファイル名変更を確認するnew_experiment.pyを追加。
初回試行はSTOPPED確認でタイムアウト。復帰処理後の親機はSDエラー累積1、NONE、P00001.CSV、子機はNONE、C00020.CSV。最初の失敗原因を特定したとは扱わない。
再試行では親機P/Q00001→00002、子機C/D00020→00021、I00014→00015に切り替わり、両機NONEを確認。既存ファイルは削除していない。今回ファーム変更・再起動なし。
Wi-Fiパスワードは親機USBから現在値を取得してユーザーに回答。秘密はこの文書には保存しない。
