# P-MAIN SD保存監査・診断改良

| 項目 | 内容 |
|---|---|
| 実施日時 | 2026-09-22 JST |
| 目的 | P-MAINのSD保存状態を非停止で確認し、間欠的なマウント失敗の切り分けと耐性を改良する |
| 対象 | P-MAIN Pico 2 W、COM6、USB serial `A444A41EE9334705`。ソースツリーに `.git` メタデータがないためcommitは不明 |
| 判定 | 一部合格。現行実機は保存継続。起動後の間欠的 `MOUNT_FAILED` 履歴を確認し、修正版はビルド/ホスト検査合格。実機書込み後の効果は未検証 |

## 前提条件

P-MAINとC-MAINはUSB接続。PCのWi-Fiは切り替えていない。P-MAINのSDカード型番、容量、ファイルシステム、SD端子3.3 V、基板版数は今回未確認。保存を継続させるため `q`、カード抜去、ファーム書込み、Wi-Fi操作は実施していない。既存ログの削除・上書き・フォーマットなし。

| 信号 | ピン・設定 | 確認 |
|---|---|---|
| SD SCK/MOSI/MISO/CS | GP10/11/12/13、SPI1 | ソース照合。電気波形は未測定 |
| SD card detect | GP15、Low=挿入、47 kΩ外付けプルアップ | 基板資料と既定義を照合。修正版の実機表示は未検証 |
| 周辺電源 | P-MAIN状態値 4.63〜4.66 V | INA226通信値。SD 3.3 Vの直接測定ではない |

## 何をしたか

1. 識別済みCOM6に読取り専用の状態要求 `h` を送り、記録を止めず2回監視した。
2. 実効実装のSPI 4 MHz直指定が、基板bring-up資料の「まず1 MHz」および宣言済み定数と不一致であることを確認。P-MAINのみ1 MHz固定、C-MAINは100 Hz IMU帯域のため4 MHz維持とした。
3. マウント前と保存中にGP15のカード検出を確認し、`CARD_NOT_PRESENT` / `CARD_REMOVED` とSPI失敗を区別した。
4. 失敗時のSdFat error code/dataを保存し、USB/API/Webでカード検出、SPI速度、詳細値を確認できるようにした。復旧成功後も最後の失敗詳細は保持する。
5. ホストテスト、Web JavaScript構文/スマホ時刻フローテスト、P-MAIN/C-MAIN 100 HzのPlatformIOビルドを実施した。

## 結果

| 確認項目 | 結果 | 判定 |
|---|---|---|
| 現行P-MAIN保存 | 起動後約480秒で299行、約876秒で695行。同期済み695行、欠落0 | 監視区間は合格 |
| 過去のSD異常 | `sd_errors=2`、`last_failure=MOUNT_FAILED`、自動復旧1回。二回の監視間で追加なし | 異常履歴あり |
| 現行最大書込時間 | 8,831 µs | 参考値。長時間最悪値の保証ではない |
| P-MAIN 1 MHz帯域 | 最大バッファ合1,088 bytes/sに対し、生SPI 125,000 bytes/s。生線路利用率上限0.870% | 計算上合格。SD内部遅延は別 |
| ホストテス | CRC/通信/時刻/電話参照/SD復旧/UTCの5実行ファイルがすべてPASS | 合格 |
| Webテスト | JavaScript構文、時刻共有、位置拒否時のフォールバックがPASS | 合格 |
| PlatformIO | `parent` / `child100` とも成功。RAM 35.9% / 45.4%、Flash 10.9% / 9.4% | 合格 |

集計は [evidence/results.json](evidence/results.json)。生のUSB状態は `reports/raw/sd_audit_20260922_COM6.txt` と `reports/raw/sd_audit_final_20260922_COM6.txt` に保存した。

## 未検証事項・次の確認

- 修正版は実機へ書き込んでいない。現在の連続記録を中断しないための措置であり、1 MHzでの再起動・長時間保存・自動復旧は未実測。
- 詳細エラー値は修正版で次回失敗した時に初めて取得できる。今回の旧ファームの2エラーはカード、接点、電源、SPI信号品質のどれかを断定できない。
- SD端子3.3 Vとリップル、SCK/MOSI/MISO/CS波形、カード型番/容量/ファイルシステム整合性は未測定。
- 実機反映時は、COM6のUSB個体とP-MAIN応答を再確認し、先に安全停止・同期完了を確認してから書き込む。
