# 親機LIS3MDLのコンソール校正

## 前提
2026-10-10。ユーザー依頼は親機磁気センサをBNO085同様にコンソールから校正すること。LIS3MDLはJ_MAG1/I2C0 GP4 SDA・GP5 SCL、通電済み。include/pins.hと隣接AquaBeacon/pcbの親子ビルド資料を照合。ピン変更・元リポジトリ変更なし。GNSS時刻同期/RTK/PPKを維持し、Spresense未変更。親機温度/水圧/LCDは検証対象外。

## 実施
10HzのLIS3MDL生値から3軸オフセットと倍率を計算し、進捗・生値・補正値・保存可否を表示。開始/保存/終了/解除、回転不足/飽和/失効の拒否、校正中の親機記録/測距再開拒否、3分の期限を実装。保存は親機停止完了後のSD新規レコード、CRC32・同期・読み戻し確認後に適用。起動時に有効な最新連番を復元。既存ログ削除/上書き/SDフォーマットなし。README・仕様・操作資料・索引を更新。

全ホストテスト成功。新規校正テストは合成楕円体のオフセット/倍率・補正結果、静止/平面回転/サンプル不足/飽和/非数/鮮度/終了/時刻wrap/期限、CRC破損/版不一致/解除レコードを確認。UIは保存可否、保存済み、通信途絶、POST操作、保存拒否の表示をオフラインで検証。既存構文・5タブ・ラベル・コントラスト検査も成功。parent/child100のビルド成功。親機RAM347676byte、Flash518208byte。

USB個体番号A444A41EE9334705とP_MAIN応答の両方でCOM6を識別し、記録停止後に親機のみ書込み成功。PC Wi-Fiは切り替えず、実機Web自動操作は実施していない。

## 実測
書込み後18秒間のUSB状態取得。LIS3MDL present=true、fresh=true、saturated=false。最終生値XYZは−19.8042/12.5402/−21.6896µT。校正未実施のためenabled/loaded/saved=false、補正値は生値と一致。これを校正合格とは扱わない。

GNSS NEO-F9P識別/config_verified=true、UTC対応候補成立。親機SD記録継続、P_MAIN_GNSS_00006.ubxにRAWX21/SFRBX49、15966byte保存、欠落0。UBXエラー/UART overflow0、RTCM保存0（サービス未設定）。時刻/位置精度を認定しない。
