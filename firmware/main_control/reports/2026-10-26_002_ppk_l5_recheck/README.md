# GPS L5有効化後のPPK再解析可否の確認

## 結果
**過去ログのPPKは実施済み。GPS L5有効化後の新しい観測を使ったPPKは未実施。** ユーザーから「まだ新しい記録は取っていない」と確認したため、今回は入力の増えていない過去ログを再解算せず、原本と既存解・現在の親機状態を照合した。

## 前提
- 2026-10-26。依頼は「L5のログも取得できているはずなので再度Fixedを試せないか、既に試していれば教えてほしい」。
- PC Wi-Fi切替、実機Web操作、記録の停止/再開、SD削除/フォーマット、ファーム書込み、設定変更なし。元リポジトリ・data原本・既存解析結果を変更しない。
- USB番号A444A41EE9334705のCOM6にhのみ送信し、role=P_MAIN応答を確認。USB状態確認は6秒間。

## 実施
- data内のUBX全7ファイルを読み取り、チェックサム有効なRAWXの信号IDを集計。過去解析inputコピーとのSHA-256一致を照合した。
- 00047/00048/00049の既存最終PPK出力を読み、解品質Qの件数を再集計。
- RINEX観測ヘッダーと最終PPKの設定/出力ヘッダーを確認。前回処理はL1+L2/E5b+L5を対象にし、Galileo E5aのC5X/L5Xを含む。GPS観測はL1のみ。

## 実測・確認結果
- 全7 UBXが過去解析inputコピーと同一。GPS観測のある00044〜00049はgnssId=0/sigId=0のみで、GPS L5観測の追加なし。00050はGPS観測なし。
- 前回主PPKのQ=1は00047で50点、00048で0点、00049で3点。三角点区間64点ではQ=1が14点、Q=2が50点で前回レポートと一致。
- 前回の三角点Q=1のみの水平差RMS 1.466 m、前向き/後向き水平差中央値1.774 mは[既存評価](../2026-10-25_008_field_gnss/README.md)による値。今回は座標誤差の再計算をしていない。信頼できるFIX・センチメートル精度の合格とは扱わない。
- 今回のUSB末尾応答：SD reason=NONE、PPK recording=true、P_MAIN_GNSS_00053.ubxへRAWX395件を保存。受信機のGPS L5設定=trueだが、瞬時の追尾GPS L5=0、位相使用=0、測位有効=false。
- 同応答で補正未接続、Wi-Fi STA未接続、RTCM保存0 byte、設定局3C722D56。現在セッションがGPS L5を保存済みとは判定しない。00053のUBX自体は今回回収/解析していない。
- 設定有効、信号追尾、RAWXへの観測保存、基準局との共通観測、後処理FIXを区別する。10月25日の有効化後に1〜2信号を追尾した証跡だけでは、新しいPPK入力の存在を意味しない。
