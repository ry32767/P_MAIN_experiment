# センサ校正・実運用可否の確認

## 前提

- 2026-10-26 JST。ユーザー依頼はセンサ校正の確認と実運用可否の評価。
- 現行ソース、既存実機レポート、同日002の保存済みUSB状態を調査。今回の新規実機測定・USB操作・校正・書込みは行っていない。
- PC Wi-Fi切替、実機Web試験、SDフォーマット・既存ログ削除、隣接リポジトリ変更は行っていない。親機温度・水圧・LCDは対象外。
- ファームウェアと仕様は変更しない。最新の保存済み状態を現在の実機状態と断定しない。

## 判定

**実運用可能と認定できない。校正用ソフトウェアは存在するが、最新の保存済み実機状態では親機IMU・磁気とも補正未適用で、校正後の独立した精度確認もない。Spresenseの記録障害も残っている。**

|---|---|---|
| Spresense IMU | 6姿勢で加速度バイアス・軸別倍率とジャイロバイアスを求める実装あり。同日USB状態はcalibration_applied=false、generation=0、mask=0 | 全6姿勢、保存・再起動復元、独立データでの補正後誤差の実測が必要 |

| 連続記録 | 10月26日001の実機記録でSpresense SDはERROR / WRITE / detail=110、記録停止 | 正常なSDで保存・読戻し・運用時間相当の負荷確認が必要 |

## 実施

- common/spresense_calibration.h、common/mag_calibration.h、common/bno_calibration.h、include/parent_calibration_store.hと関連テストを確認。
- IMUは静止・姿勢・分散・欠落を検査するが、温度補償、軸間非直交、ジャイロ倍率の同定を含まない。Sony内部フラッシュ校正ではなく、ドライバ出力への追加補正。
- 磁気は対角倍率モデルで、軸間項のある完全な楕円体補正を含まない。傾斜・取付回転・磁気偏角を考慮した方位の精度保証もない。高度な補正の追加が必須かは、独立した実測誤差と必要精度で決める。
- IMU・磁気の回転/位置はセットに保持できるが、最新記録は配置未確認。統合した姿勢・位置推定の運用合格とは扱わない。
- 指定環境のPythonでscripts/test_host.pyを実行し、終了コード0。既存の校正・保存・CRC・ガード等の模擬試験を含め全件成功。実機WebやWi-Fi切替スクリプトは実行していない。
- ST AN3192を一次資料として確認。磁気のオフセット/倍率補正に加え、取付ずれ・傾斜と独立した方位試験が評価対象である。LSM303DLH向け資料の校正原理を参照し、LIS3MDLの部品精度へ転用しない。

## 未検証・実運用前の確認順

1. Spresense SDの保存障害を解消し、既存ログを保全した正常な媒体で保存・読戻しを確認する。
2. 使用地点の重力・緯度を確認し、IMU全6姿勢と磁気全方向の実機校正を実施。保存・終了後、再起動して同じ係数と番号の復元を確認する。子機接続後はBNOの保存と電源再投入保持も確認する。
3. 校正に使っていない姿勢・方位で基準と比較する。IMUの静止加速度、静止ジャイロと既知回転、磁気の水平/傾斜時方位、送信・電源負荷の影響を測る。
4. 必要な角度・加速度・時刻・距離の許容誤差と運用時間を決め、その範囲・温度条件で連続ログと精度を評価する。合格値は現時点で未設定・未実測。
5. 個別校正後に親機セットを保存し直す。姿勢/位置の統合利用を行う場合は機体への取付回転・位置も確認する。

校正画面の「保存可能」「保存済み」「個別校正一致」は、実運用精度の合格表示ではない。現段階は校正・基準比較を進める試験段階。
