## 実施
- 状態の先頭に親機・Spresense・子機の3カード。電池・SD・異常を常時表示し、カードを押すと詳細を展開。開閉状態は定期更新で変更しない。
- 親子の電池は従来の電圧目安。Spresenseには電池値の通信項目がないため「計測情報なし」。未接続子機の値を正常や0%として扱わない。
- 異常は赤い枠・背景・原因文で表示。過去のカウンタは累計/履歴と明記。概要は先頭2件と残件数に抑え、全件を詳細へ表示。正常停止、最初から未接続、接続後の通信途絶を区別する。
- 校正は機器別に閉じた項目へ整理。「子機 BNO085」と明記し、位置・姿勢・CAD等の入力欄を削除。
- 親機セットの新しいreference_only=1操作は個別校正参照だけを更新。既存配置・識別情報・保存ABIを保持し、新規セットを追記する。既存の保存ガードと従来APIを維持する。
- 時刻・位置に測位・時刻源・PPK要約を追加し、接続・信号/保存診断・スマホ共有・UTC/RTC・GNSS同期を閉じた項目へ整理。従来の情報・設定・RTK検索を保持する。
- ログ・SDは3台ごとに保存開始/復旧・停止を配置。親子は既存の制御3/2、Spresenseは既存START/STOPを使用。SpresenseのSD/通信診断・再起動を同タブへ移動。受付と完了の表示を区別する。
- 子機未接続時は子機SD・BNO校正等の操作を無効にし、別の操作が終わっても再有効化しない。
- UIロジックはブラウザー上で実行し、ページは従来どおり親機フラッシュから配信。新しい機体用バッファ・テレメトリー通信を追加しない。
- README・docs/spec.md・docs/parent_calibration.md・web/DESIGN.mdを同期。docsの増減なし。
