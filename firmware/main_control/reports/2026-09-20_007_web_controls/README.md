# Web実験操作
親機Webに測距開始/停止、親子記録停止/再開・新規実験、BNO50/100Hz切替・再初期化、受信ゲイン確認、親子SDログ一覧/回収を実装。操作は子機への応答付きテザー通信を使用。親機と子機100Hzに書込み済み。

## 実機API検証
親機APに接続して、親子INFO、保存停止/再開、測距開始/停止、子機50→100Hz切替、ADCモニター開始/集計取得/停止を確認。親子ログ一覧とCSV回収を実行し、CRC一致を確認した。test_web_controls.pyでPASS。最終cleanupで送信停止・子機モニター停止・親子記録再開を実施。
[詳細](web_controls_result.json)、[親機回収CSV](web_download_p.csv)、[子機回収CSV](web_download_c.csv)。

## その他の検証
parent/child100ビルド成功。既存ホスト試験にCONTROLペイロード・CRC・固定サイズ・ファイル名のパス拒否を追加し成功。UI JavaScript構文検査成功。
実機ブラウザでの画面全体とボタン操作確認は未完了。アプリ内ブラウザは接続タイムアウト、PCのWi-Fi切替がCodex接続を妨げるため、ユーザー指示で切替検証を停止した。今後の実機画面確認はユーザーが行う。API確認とブラウザ操作確認を混同しない。

## 制約
実際の濡れ刺激、距離精度、物理故障/満杯/電源断、大容量ファイルをブラウザで最後まで回収する試験は未実施。制御通信再送のキャッシュ動作はコード実装済みだが、実機でACKだけを故意に落とす試験は未実施。通常測距はブラウザ切断後も継続する。60秒テストのみ送信の自動停止あり。
