## 実施
- IMU：6姿勢の未測定/測定中/やり直し/測定条件通過、現在姿勢の進捗、次の動作を表示。保存・係数チェックの通過とSD保存/復元失敗を区別。通信失効やIMU未取得時は現在の進捗を隠す。
- 既存の校正拒否条件を理由bitへ分類。データ欠落/間隔、非数、回転、重力範囲、選択姿勢、急変、点数、区間分散を伝える。閾値・補正の数式・保存条件は維持。直近理由は履歴として保持し、姿勢選択で解除する。条件外サンプル・区間の回数は16bit飽和表示で、測定試行回数とは呼ばない。
- D03の128byte/版3を維持。PPS診断Navの未使用標高領域へ0xCAマーカー・理由・回数を格納。PPS/UTC/SD領域や取得設定を変えない。旧Spresenseは診断未取得として表示し、本来の位置データを診断と誤解釈しない。親機とSpresense loggerの更新が必要。
- 磁気：接続/鮮度/時間/点数/XYZ幅/8方向/飽和/半径ばらつき/半径整合を表示し、不足をまとめる。計算可能性と半径整合をAPIへ追加。幅不足でCV初期値が0のときに通過と表示しない。最終の保存可否は装置readyに従う。更新が5秒途絶すると条件と案内を不明へ戻す。数値/保存情報は展開できる詳細に保持。
- BNO：加速度なら姿勢変更・静止、ジャイロなら静止、磁気なら多軸回転を案内。全て中以上でも装置の継続判定を待つ。状態不明・未知の状態値を成功扱いしない。
- README、docs/spec.md、docs/parent_calibration.md、web/DESIGN.mdを同期。docsの増減なし。既存の色・余白・幅・操作IDと停止/未接続ガードを維持。
