# 2026-09-20 受信ゲイン再試験・60秒ライブ表示

ユーザーより可変抵抗器のゲインが未調整だったとの連絡を受け、接続済みの水中振動子（小容器内・数cm）で再試験した。Spresense、LCD、親機温度・圧力は対象外。

子機にUSB診断用ADC DMAモニターを追加。SD停止確認後、ENV_ADCを100 kSa/sで連続取得し、20 msごとの最小・平均・最大をリアルタイム表示。親機は既存の1 Hz・200 kHz・5波バースト。ADC DMA取得中は他のanalogReadを禁止。16384サンプルリングの欠損数を報告し、75秒でADC自動停止。PC側は60秒後に親機送信停止・子機ADC停止・SD再開を実施。

## 実測

- 60秒、3000窓（600万ADCサンプル相当）、報告されたリング欠損0。
- ENV_ADC最小1776 mV、最大1863 mV。各窓平均1824〜1827 mV。
- 比較器HIGH、受信エッジ0。親機で観測できた59シーケンスはいずれも状態5（HIGH固定）。受信・距離の成立は確認できなかった。
- 電圧はADCの3.3V基準換算。音圧・dBではなく、ADCの絶対電圧校正は未実施。物理的な送信波形はオシロスコープ未確認。
- 計測終了後、親機ranging=false、親子sd_reason=NONE、子機の記録再開204行を確認。SDエラー0・キュー欠損0。
- 画面の横軸はPC受信時刻。保存データのt_usおよび下図は子機ADC取得時刻。ライブ表示中の画面更新とグラフ描画を実際に確認。

## 検証・再利用

parent/child50/child100ビルド成功、既存ホスト試験成功。子機child100のみUSB識別・SD停止後に書込み。`python scripts/gain_monitor.py` で http://127.0.0.1:8777 を起動し、ボタンから再計測可能。子機SDは計測中のみ一時停止する。PCが異常終了すると子機ADCは75秒で停止するが、SD再開と親機停止は手動で必要（子機n/s、親機X）。
